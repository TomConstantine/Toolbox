iOS / iPhone Web Bluetooth

Apple Safari on iOS currently disables native Web Bluetooth (`navigator.bluetooth`). To connect your physical RTK receiver on iPhone/iPad, choose one of these solutions:

Option A: Web Bluetooth Browsers (Free)

Download one of these free iOS browsers from the App Store that enable Web Bluetooth API support:

  • Blueify - Web Bluetooth Browser
  • WebBLE Browser
Option B: NMEA Log File or Demo Mode

You can use our built-in RTK Simulator or load an offline `.nmea` text log directly in standard iOS Safari.
